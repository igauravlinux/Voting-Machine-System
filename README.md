# 🗳️ Online Voting Machine (Java)

## 📌 Overview

This project is a console-based Online Voting System developed using Java.
It allows users to cast their vote securely while ensuring that each user can vote only once.

---

## 🚀 Features

* 🔐 User Authentication System
* 🗳️ One Person One Vote Validation
* 📊 Automatic Vote Counting
* ⚡ Fast and Efficient Console-Based Interface

---

## 🛠️ Technologies Used

* Java
* Conditional Statements
* Basic Data Structures
* Object-Oriented Programming (OOP)
* Arraylist
* String
* Exception Handling

---

## 📂 How It Works

1. User enters credentials
2. System verifies voter eligibility
3. User casts vote
4. Vote is recorded securely
5. Final results are calculated and displayed
